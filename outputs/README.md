# Outputs

This directory contains the outputs generated by the apple detection and segmentation pipeline.

## Scripts

The main scripts are located in `src/`:

- `apple_segmenter_v1.py` — Segmentation baseline using RF-DETR.
- `apple_predictor.py` — Custom apple localisation/detection algorithm using RGB, depth, and branch GT information.
- `apple_segmenter_train.py` — Training script for the RF-DETR apple segmentation model.

## Running the Scripts

Run all scripts from the **project root** using the `src/` path.

### Apple Predictor

```bash
python src/apple_predictor.py
```

Outputs are saved to:

```text
outputs/apple_detection/
├── annotated/
└── apple_counts.csv
```

### Apple Segmenter Baseline

```bash
python src/apple_segmenter_v1.py
```

Outputs are saved to:

```text
outputs/apple_rfdetr/
├── annotated/
├── masks/
└── apple_counts.csv
```

The segmentation script uses the trained RF-DETR checkpoint:

```text
outputs/rfdetr_apple_tree/checkpoint_best_total.pth
```

### Train the Apple Segmenter

```bash
python src/apple_segmenter_train.py
```

Training outputs and checkpoints are saved under:

```text
outputs/
```

> **Note:** Generated outputs, model checkpoints, and other large files are not included in the repository and are ignored by Git.
