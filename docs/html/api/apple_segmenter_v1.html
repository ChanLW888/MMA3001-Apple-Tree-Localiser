apple_segmenter_v1¶

Source: src/apple_segmenter_v1.py.

Statically extracted signatures and existing docstrings; no module execution.

Run branch-guided RF-DETR apple instance segmentation.

Reads outputs/rfdetr_apple_tree/checkpoint_best_total.pth and writes outputs/apple_rfdetr_instances. Defaults to summer branch GT (>127) with central placement. Predicted mode only reads exported <RGB-stem>_branch.png masks. Does not run branch inference or consume depth. Model detections are not verified apple annotations.

Example

python src/apple_segmenter_v1.py

apple_segmenter_v1.align_branch_mask(mask: np.ndarray, image_shape, alignment: str)¶

Place a binary branch mask in original RGB coordinates.

Thresholds >127 before resizing. Same-size masks return directly. center_crop expands to min(H, W) square and centres on a zero canvas; full_resize stretches over the frame. Neither verifies true GT geometry. Input encoded as 0/1 becomes empty.

Parameters:

  • mask – numpy.ndarray; grayscale [Hm, Wm] or BGR mask, expected 0/255 encoding.

  • image_shape – tuple[int, …]; starts with original (height, width).

  • alignment – str; full_resize or center_crop when shapes differ.

Returns:

uint8 [H, W] branch mask in {0, 1}.

Return type:

numpy.ndarray

Raises:

  • ValueError – If shapes differ and alignment is unsupported.

  • cv2.error – If conversion or resizing fails.

branch_mask – numpy.ndarray; aligned [H, W], foreground >0.

apple_segmenter_v1.filter_instances(detections, image_shape, zone)¶

Retain whole RF-DETR masks with sufficient branch-zone overlap.

Missing masks/confidences yield no instances. Current constants require confidence >=0.20, mask >0.50, area >=1 and overlap >=0.05. Uses nearest-neighbour resizing. No class-ID filtering occurs; checkpoint is assumed apple-only. Masks remain whole, not clipped to the zone.

Parameters:

  • detections – RF-DETR/supervision detections with mask [N, Hm, Wm] and confidence [N], or None.

  • image_shape – tuple[int, …]; original (H, W, …) shape.

  • zone – numpy.ndarray; aligned binary [H, W] proximity region.

Returns:

mask (bool [H, W]), confidence, area (pixels), overlap,

inclusive xyxy bbox and mean (x, y) centroid.

Return type:

list[dict]

Raises:

  • ValueError – If a mask is not 2D or zone cannot broadcast.

  • cv2.error – If resizing fails.

apple_segmenter_v1.save_outputs(image, image_path, branch, zone, instances)¶

Write cyan annotations, uint16 instance IDs and branch-zone PNGs.

ID 0 is background; instances start at 1. Later masks overwrite earlier IDs at overlaps; CSV areas still describe whole instances.

Parameters:

  • image – numpy.ndarray; uint8 [H, W, 3] BGR.

  • image_path – pathlib.Path; stem names saved files.

  • branch – numpy.ndarray; accepted but unused.

  • zone – numpy.ndarray; [H, W] binary 0/1 proximity mask.

  • instances – list[dict] from filter_instances.

Returns:

Annotated image,

instance-ID mask and zone image.

Return type:

tuple[pathlib.Path, pathlib.Path, pathlib.Path]

Raises:

  • ValueError – If count exceeds uint16 capacity.

  • OSError – If directories or image files cannot be written.

  • cv2.error – If encoding or drawing fails.

apple_segmenter_v1.main()¶

Load RF-DETR and export branch-guided apple predictions.

Defaults to summer branch GT with central placement. Skips missing/unreadable inputs and unexpected names. Recreates CSVs even for START_FRAME >1. model.predict reads RGB paths; no depth input is used. Initialisation may require cached auxiliary weights.

Returns:

None.

Raises:

  • FileNotFoundError – If RGB directory or checkpoint is missing.

  • ImportError – If rfdetr cannot be imported.

  • ValueError – If overlap/start-frame settings, mask rank or alignment are invalid.

  • RuntimeError – If no selected PNGs exist or model execution fails.

  • OSError – If outputs cannot be written.

main.sync_cuda()¶

Synchronise pending CUDA work for inference timing.

Does nothing without CUDA; barriers keep asynchronous kernels inside the timed interval.

Returns:

None.

Raises:

RuntimeError – If CUDA synchronisation fails.
