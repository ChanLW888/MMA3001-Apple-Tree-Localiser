winter_inference¶

Source: src/winter_inference.py.

Statically extracted signatures and existing docstrings; no module execution.

Run qualitative winter RGB-D inference and model-only timing.

Reconstructs training MLP/basic/improved U-Nets without ImageNet weight retrieval, then strictly loads trusted local checkpoints. Uses training-compatible preprocessing. No winter GT is required; predictions cannot establish winter accuracy. Timing excludes preprocessing, transfer, sigmoid and saving.

Requires winter RGB-D pairs and all three local model checkpoints. Writes masks, overlays, panels, per_image_timings.csv, summary.csv and benchmark_metadata.json under outputs/winter_inference_benchmark by default. Reruns overwrite matching names.

Example

See README.md for the invocation supplying all three checkpoints.

winter_inference.preprocess(s, size)¶

Apply training-compatible RGB-D preprocessing.

Centre-crops both modalities; RGB is bilinear, /255 then ImageNet standardised. Depth is nearest neighbour, grayscale /255, not metric distance.

Parameters:

  • s – dict with rgb and depth pathlib.Path entries.

  • size – int; positive square input side in pixels, normally 256.

Raises:

  • ValueError – If resize dimensions are invalid.

winter_inference.benchmark(model, samples, name, outroot, device, size, threshold, warmup)¶

Measure model-only latency and export winter predictions.

Caller sets eval mode; inference_mode disables gradients. Timing excludes preprocessing, transfer, sigmoid, thresholding and saving. Sample standard deviation uses ddof=1 for at least two images; absent means are None.

Parameters:

  • model – torch.nn.Module; eval model on device mapping RGB-D to branch logits.

  • samples – list[dict] from discover.

  • name – str; model label and output subdirectory.

  • outroot – pathlib.Path; root output directory.

  • device – torch.device matching model parameters.

  • size – int; positive input side matching training geometry.

  • threshold – float in [0, 1]; inclusive sigmoid cutoff.

  • warmup – int; nonnegative untimed first-sample forward passes.

Returns:

Per-image timings and summary in milliseconds;

throughput is model-only images/second.

Return type:

tuple[list[dict], dict]

Raises:

  • OSError – If input reading or prediction saving fails.

  • RuntimeError – If inference or synchronisation fails.

winter_inference.main()¶

Load three checkpoints and benchmark paired winter images.

Requires –data-root and –mlp-checkpoint, –unet-checkpoint, –improved-checkpoint. Saves per_image_timings.csv, summary.csv, benchmark_metadata.json and model-specific images. Input size comes from CLI, not checkpoint metadata. Requires no GT.

Returns:

None.

Raises:

  • SystemExit – If required CLI arguments are missing or –help is requested.

  • FileNotFoundError – If a required path is absent.

  • RuntimeError – If pairing, loading or inference fails.

  • OSError – If inputs/outputs cannot be accessed.
