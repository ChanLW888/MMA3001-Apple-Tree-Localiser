compare_apple_detectors¶

Source: src/compare_apple_detectors.py.

Statically extracted signatures and existing docstrings; no module execution.

Compare traditional predictions with RF-DETR pseudo-ground truth.

Matches exact basenames and original-image centroids from saved CSVs. One-to-one matching maximises valid pairs before minimising distance. Agreement is not independently verified accuracy. Runs no detector inference. Generated report prose includes fixed historical statements that this program does not verify.

Example

python src/compare_apple_detectors.py –max-distance 30 –thresholds 10 20 30 40 50

Validate and group inclusive-coordinate instance records.

IDs are positive and unique per image. Finite nonnegative coordinates must contain the centroid; image bounds are checked later by main. Confidence may be blank or NaN; finite scores must be in [0, 1]. Duplicate geometry is retained.

duplicate-geometry warnings.

tuple[dict[str, list[dict]], list[dict]]

compare_apple_detectors.match_centroids(reference, traditional, threshold)¶

Maximise valid one-to-one pairs, then minimise summed distance.

Hungarian assignment adds unmatched dummy columns. A penalty larger than any valid total prioritises cardinality over distance. RF-DETR is pseudo-ground truth, not independently verified apple annotation.

Parameters:

  • reference – Sequence[dict] with RF-DETR cx_px and cy_px.

  • traditional – Sequence[dict] with traditional cx_px and cy_px.

  • threshold – float; finite nonnegative inclusive Euclidean tolerance in original-image pixels.

Returns:

Reference index, traditional index and

distance; empty if either sequence is empty.

Return type:

list[tuple[int, int, float]]

Raises:

ValueError – If threshold is negative/nonfinite or assignment costs are invalid.

compare_apple_detectors.evaluate(images, ref, pred, threshold)¶

Summarise fixed detections over common processed images.

Missing instance keys imply zero detections. Count error is traditional minus reference. Distance/IoU statistics condition on accepted matches; absent samples yield None. Global agreement is micro; image_macro_f1 averages per-image F1.

Parameters:

  • images – Nonempty reusable collection[str] of common exact basenames, including zero-count frames.

  • ref – Mapping[str, list[dict]] of RF-DETR pseudo-reference records.

  • pred – Mapping[str, list[dict]] of traditional records.

  • threshold – float; finite nonnegative inclusive tolerance in pixels.

Returns:

Per-image metrics, matched/unmatched

pairs and aggregate summary.

Return type:

tuple[list[dict], list[dict], dict]

Raises:

  • ValueError – If matching tolerance is invalid.

  • ZeroDivisionError – If images is empty.

compare_apple_detectors.main()¶

Compare saved CSVs without rerunning either detector.

Writes metrics, sensitivity, coverage, examples, SHA-256 manifest and annotation inventory. Defaults to apple_rfdetr_instances and apple_detection under outputs. Current source is not proof of historical CSV provenance. Embedded report prose is fixed program data, not verified experiment history.
