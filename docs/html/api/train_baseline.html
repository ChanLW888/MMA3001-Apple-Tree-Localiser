train_baseline¶

Source: src/train_baseline.py.

Statically extracted signatures and existing docstrings; no module execution.

Train a pixel-wise RGB-D MLP for binary branch segmentation.

Float32 input [B, 4, S, S] is ImageNet-standardised RGB plus grayscale depth/255. GT [B, 1, S, S] uses intensity >127 as branch by default and must already match the centred field of view. The MLP has no spatial context. Uses positive-weight-12 BCE, Adam, seeded sample splitting and best-validation-Dice selection. Validation is not independent testing.

Example

python src/train_baseline.py –data-root data/Organised

class train_baseline.BranchDataset(Dataset)¶

Load aligned RGB-D inputs and binary branch targets.

RGB and depth are centre-cropped and resized. GT is neither cropped nor resized; it must already describe that field of view at input_size. Channel order is R, G, B, then grayscale depth. Depth is image intensity, not calibrated metres.

class train_baseline.PixelMLP(nn.Module)¶

Classify each RGB-D pixel independently using dense layers.

Flattening pools pixels into a batch without mixing neighbours; output is a raw branch logit per pixel.

Train, select by validation Dice and export checkpoint and metrics.

Uses a seeded shuffled sample split, not a held-out tree split. Writes history.csv, val_metrics.csv and visualisations. Checkpoint selection uses the same validation set. Use positive epochs and validation fraction strictly between 0 and 1.
