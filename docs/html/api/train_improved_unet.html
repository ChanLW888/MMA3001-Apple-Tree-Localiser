train_improved_unet¶

Source: src/train_improved_unet.py.

Statically extracted signatures and existing docstrings; no module execution.

Train branch segmentation with ASPP, attention and residual decoding.

Preprocessing matches train_unet.py: float32 [B, 4, S, S] RGB-D to [B, 1, S, S] logits. Uses plain BCE, AdamW (weight decay 1e-4), a validation-Dice plateau scheduler and paired flips. RGB brightness/contrast perturbation operates after normalisation, leaving depth unchanged. Architecture intent does not establish improved measured accuracy.

Example

python src/train_improved_unet.py –data-root data/Organised –no-pretrained

class train_improved_unet.BranchDataset(Dataset)¶

Load aligned RGB-D inputs and binary branch targets.

RGB and depth are centre-cropped and resized. GT is neither cropped nor resized; it must already describe that field of view at input_size. Channel order is R, G, B, then grayscale depth. Depth is image intensity, not calibrated metres.

class train_improved_unet.ImprovedResNet34UNet(nn.Module)¶

Predict branch logits with a four-channel ResNet-34 U-Net.

ASPP supplies multiscale context, attention weights skip features, and residual blocks fuse them. With pretraining, RGB filters are retained and their mean initialises depth.

train_improved_unet.evaluate(model, loader, device, threshold)¶

Aggregate validation loss and foreground pixel metrics.

Sets evaluation mode and disables gradients. Uses sigmoid(logits) >= threshold and targets >=0.5. Epsilon 1e-8 stabilises ratios; empty foreground scores zero.

Parameters:

  • model – torch.nn.Module mapping [B, 4, H, W] to [B, 1, H, W] logits.

  • loader – DataLoader yielding input, target and identifier batches.

  • device – torch.device; model must already be on it.

  • threshold – float; inclusive sigmoid cutoff, normally [0, 1].

Returns:

Sample-weighted loss and pixel-micro dice, iou, precision

and recall.

Return type:

dict[str, float]

Raises:

  • OSError – If dataset inputs cannot be read.

  • RuntimeError – If dataset geometry or model execution fails.
