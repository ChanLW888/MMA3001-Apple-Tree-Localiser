apple_predictor_v1¶

Source: src/apple_predictor_v1.py.

Statically extracted signatures and existing docstrings; no module execution.

Detect red apples with depth validity and branch ground truth.

A 2D image-space baseline, not metric 3D localisation. Branch GT (>0) is stretched to the full RGB grid and dilated. RGB/depth must be aligned. Writes annotation PNGs, counts, instances, timings and metadata under outputs/apple_detection.

Example

python src/apple_predictor_v1.py

apple_predictor_v1.load_gt(path, target_shape)¶

Load branch ground truth and stretch it to the RGB grid.

Nearest-neighbour interpolation preserves labels. Full-frame stretching differs from RF-DETR default central placement; it does not verify annotation geometry.

Parameters:

  • path – str or pathlib.Path; branch GT image, not apple-instance annotation.

  • target_shape – tuple[int, int]; positive original (height, width) in pixels.

Returns:

uint8 [H, W] grayscale GT; foreground is interpreted

downstream as >0.

Return type:

numpy.ndarray

Raises:

  • OSError – If GT cannot be decoded.

  • cv2.error – If resize dimensions are invalid.

apple_predictor_v1.detect_red_mask(rgb, depth)¶

Select red-dominant pixels with valid depth.

Floating channel arithmetic avoids uint8 overflow. Thresholds are module constants; depth supplies validity, not 3D coordinates.

Parameters:

  • rgb – numpy.ndarray; [H, W, 3] RGB intensities in [0, 255].

  • depth – numpy.ndarray; aligned [H, W] values, valid when >0.

Returns:

uint8 [H, W] binary mask.

Return type:

numpy.ndarray

Raises:

ValueError – If depth cannot broadcast to the RGB grid.

apple_predictor_v1.clean_red_mask(mask)¶

Suppress isolated red noise and close small gaps.

The ellipse is MORPH_KERNEL_SIZE pixels wide/high. Morphology may merge nearby regions; components are candidates rather than guaranteed apples.

Parameters:

mask – numpy.ndarray; uint8 [H, W] binary red mask.

Returns:

uint8 [H, W] opened then closed mask.

Return type:

numpy.ndarray

Raises:

cv2.error – If mask or kernel is invalid.

apple_predictor_v1.create_branch_zone(gt)¶

Dilate labelled branch pixels into a proximity region.

BRANCH_DILATION is ellipse diameter in source-image pixels, not radius. Uses ground-truth branches, not predicted segmentation.

Parameters:

gt – numpy.ndarray; aligned [H, W] branch GT, foreground >0.

Returns:

uint8 [H, W] zone in {0, 1}.

Return type:

numpy.ndarray

Raises:

cv2.error – If morphology input or kernel is invalid.

apple_predictor_v1.find_apple_candidates(rgb, depth, gt)¶

Filter connected red components by geometry and branch proximity.

Original-image coordinates: top-left origin, x right, y down. Overlap is intersection/whole-component area. Red score is mean R/(G+B+1), not calibrated confidence. No apple labels are read.

Parameters:

  • rgb – numpy.ndarray; uint8 [H, W, 3] RGB.

  • depth – numpy.ndarray; aligned [H, W] depth-validity intensities.

  • gt – numpy.ndarray; aligned [H, W] branch ground truth.

Returns:

label, area (pixels), bbox (x, y, width, height), centroid (x,

y), circularity, aspect_ratio, branch_overlap and red_score.

Return type:

list[dict]

Raises:

  • ValueError – If RGB/depth/GT spatial shapes differ.

  • cv2.error – If image processing fails.

numpy.ndarray

apple_predictor_v1.instance_rows(result)¶

Export components in the shared instance-CSV convention.

confidence is intentionally blank; red_score is an uncalibrated colour statistic.

Parameters:

result – dict with image, instances, image_width and image_height.

Yields:

dict –

One row per candidate with 1-based apple_id, inclusive xyxy box and

mean-pixel centroid in original RGB coordinates.

Raises:

KeyError – If required result/candidate fields are absent.

apple_predictor_v1.save_csv(results)¶

Write counts, instances, timing CSVs and run metadata.

Overwrites configured CSVs. Durations are milliseconds. Metadata records traditional parameters and GT full-resize alignment.

Parameters:

results – list[dict]; process_frame results with total_ms added by main.

Returns:

None.

Raises:

  • KeyError – If any export field, including total_ms, is missing.

  • OSError – If output creation or writing fails.

apple_predictor_v1.main()¶

Process configured frames and export traditional detector outputs.

Configuration uses module constants, not CLI flags. Prints and returns without exports when no complete frames exist.

Returns:

None.

Raises:

  • ValueError – If RGB/depth geometry differs.

  • OSError – If input reading or output writing fails.

  • cv2.error – If processing fails.
