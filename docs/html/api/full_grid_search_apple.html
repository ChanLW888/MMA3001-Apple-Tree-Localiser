full_grid_search_apple¶

Source: src/full_grid_search_apple.py.

Statically extracted signatures and existing docstrings; no module execution.

Full Cartesian grid search for traditional apple-detector parameters.

Place in src/ beside apple_predictor_v1.py and compare_apple_detectors.py. Run from the repository root: python src/full_grid_search_apple.py

All 5,184 combinations are evaluated against the existing RF-DETR instance CSV. Only traditional colour/component/morphology constants vary. Branch-region constants, GT alignment, matching threshold and RF-DETR files are unchanged. A resumable all_experiments.csv is appended after each successful configuration. See main for fingerprint coverage and the held-out objective-change limitation. By default tune on development trees, then compare the chosen model with the baseline on separate held-out trees. No annotated PNGs or per-run CSVs are made.

full_grid_search_apple.combinations()¶

Enumerate the Cartesian product of the current module GRID.

Grid insertion order determines run IDs. The current seven parameter lists produce 4 * 4 * 4 * 3 * 3 * 3 * 3 = 5,184 configurations. Branch dilation and overlap are absent from the grid and remain fixed.

Yields:

tuple[str, dict] – Zero-based grid_NNNN ID and detector constants. Each call produces new parameter dictionaries.

full_grid_search_apple.score(row, metric)¶

Map a supported optimisation objective to a larger-is-better score.

Parameters:

  • row – Mapping containing evaluation metric columns.

  • metric – One of f1, precision, recall, mae, rmse, centroid, bbox_iou, count_bias. Errors/distances are minimised, agreement maximised, and signed bias minimised in absolute magnitude.

Returns:

Oriented score; most invalid metrics become negative infinity.

Return type:

float

Raises:

  • KeyError – If metric is unknown or count_bias lacks its input column.

  • ValueError – If count_bias cannot be converted to float.

  • TypeError – If count_bias has an incompatible value type.

Note

Unlike other objectives, count_bias does not reject nonfinite values.

full_grid_search_apple.evaluate_configuration(params, frames, names, predictor, comparator, reference, threshold)¶

Evaluate cached synthetic or real frames without exporting images.

Mutates predictor constants in memory; this helper does not restore them. The main search restores baseline constants in a finally block.

Parameters:

  • params – Mapping of detector constant names to parameter values.

  • frames – Iterable of (filename, info, rgb, depth, branch) tuples. RGB has shape [H, W, 3]; aligned depth and branch masks have shape [H, W]. The info element is unused here.

  • names – Nonempty reusable collection of exact basenames to evaluate.

  • predictor – Module-like object exposing detector and instance_rows APIs.

  • comparator – Module-like object exposing evaluate.

  • reference – Mapping of basenames to saved RF-DETR instance records.

Returns:

Aggregate comparison metrics and elapsed seconds for detection/instance conversion, excluding comparison evaluation.

tuple[dict, float]

full_grid_search_apple.main()¶

Run or resume traditional parameter tuning against saved RF-DETR results.

Reads command-line options through argparse; use –help for paths, selection objectives, by-tree/all splits, caching and partial-run options.

Returns:

None. Appends all_experiments.csv and rewrites best_by_metric.csv and metric_rankings.csv. Writes grid_metadata.json and, only after a complete by-tree search, heldout_comparison.csv if that file does not already exist.

Raises:

  • ValueError – If baseline/fixed branch settings differ, common inputs or partitions are empty, or resume metadata/CSV columns are incompatible.

  • FileNotFoundError – If configured source or reference files are missing.

  • OSError – If image/CSV reading or result writing fails.

  • SystemExit – For argparse help or invalid arguments.

Note

Branch dilation is fixed at 100 pixels and minimum overlap at 0.05. Complete traditional RGB/depth/GT triplets are intersected with reference count basenames, preserving zero-count images. GT is stretched to RGB geometry. Images are cached in RAM unless –no-cache reloads each run. The no-cache path still materialises the entire split as a list; it is not a bounded-memory stream. The preceding iteration’s current_frames remains referenced while the next list is built, so peak memory can include two split-sized image lists. The CLI help’s RAM-reduction intent has not been established by this implementation. RF-DETR CSV predictions are pseudo-reference, never new inference.

Metrics include micro precision/recall/F1, image macro F1, signed and absolute counting errors, RMSE, count agreement rates, conditional centroid distances in pixels and inclusive-box IoU. By-tree mode tunes development trees and evaluates only the selected configuration and baseline on test trees; –split all provides no held-out estimate.

Resume checks grid, source/reference hashes and development-name hash, then skips recorded run IDs. Image bytes, environment versions and test names are not fully fingerprinted. Timing depends on machine/load. Source docstring edits also change hashes and require a fresh output directory.

Known limitation: –select-by is not included in metadata, and an existing heldout_comparison.csv is never refreshed. A changed objective can reuse stale held-out results. Use a separate output directory per objective; retain original results. Partial rankings are not exhaustive optima.
