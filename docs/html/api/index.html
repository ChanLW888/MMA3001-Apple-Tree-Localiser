Source API reference¶

All maintained Python modules under src/ are parsed using Python’s AST parser. Sphinx Napoleon formats existing Google-style docstrings. Signatures, classes, methods, nested helpers, parameters, returns and exceptions are included where documented. Missing prose is labelled rather than invented. Imported third-party members, inherited APIs and dynamically created objects are not expanded; runtime behaviour and annotation resolution are not verified. Constants are not evaluated.

The organiser copies files on import; COCO preparation and RF-DETR training check paths on import. Static extraction avoids these side effects for every module.
