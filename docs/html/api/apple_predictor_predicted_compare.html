apple_predictor_predicted_compare¶

Source: src/apple_predictor_predicted_compare.py.

Statically extracted signatures and existing docstrings; no module execution.

Use improved U-Net branch predictions for traditional apple detection, then compare.

Run from the repository root with the mma3001 environment:

python src/apple_predictor_predicted_compare.py

Default workflow: load a trusted improved U-Net checkpoint, infer a branch mask for each summer RGB-D frame, put the checkpoint-sized square prediction (256 by default) back into the central square of the original RGB image, run the UNCHANGED traditional apple candidate detector, export compatible prediction CSVs, and immediately compare them against the EXISTING RF-DETR pseudo-reference CSVs. The RF-DETR model is NOT run or modified.

Optional –also-gt-control runs an equivalent traditional detection experiment with GT branch masks using the SAME centre-square alignment. This is a more controlled comparison of predicted vs GT branches than using historical full-resize results.

IMPORTANT: On summer training/validation images this is not an independent test of branch-network generalisation. RF-DETR CSVs are pseudo-ground truth, not apple GT.

apple_predictor_predicted_compare.centre_square_mask(mask_2d: np.ndarray, image_shape: tuple[int, int]) → np.ndarray¶

Project branch foreground into the original image’s central square.

Uses nearest-neighbour resize to min(H, W), then zero padding. Unlike RF-DETR’s helper, there is no same-size shortcut: every mask is projected. Nonsquare 2D inputs are stretched to a square, not explicitly rejected.

Parameters:

  • mask_2d – numpy.ndarray [Hm, Wm]; values >0 denote foreground.

  • image_shape – tuple[int, int]; positive original (height, width), pixels.

Returns:

uint8 [H, W] mask encoded 0/255.

Return type:

numpy.ndarray

Raises:

  • ValueError – If mask_2d is not 2D or image_shape cannot be unpacked.

  • cv2.error – If input or resize dimensions are invalid.

apple_predictor_predicted_compare.load_improved_model(checkpoint_path: Path, requested_device: str)¶

Load a local improved U-Net checkpoint without training or downloads.

Reconstructs winter_inference.ImprovedUNet with weights=None, strictly loads state keys, moves to the selected device and enters evaluation mode. weights_only=True restricts deserialisation; use trusted local files.

Parameters:

  • checkpoint_path – pathlib.Path to a checkpoint dictionary containing model_state_dict and optionally input_size, or a bare state dict.

  • requested_device – str; auto, cpu or cuda as constrained by the CLI.

Returns:

Model, torch module, winter_inference module, torch.device, integer input side (checkpoint input_size or 256), and checkpoint dict.

Return type:

tuple

Raises:

  • FileNotFoundError – If the checkpoint is absent.

  • TypeError – If the loaded checkpoint is not a dictionary.

  • RuntimeError – If CUDA is unavailable, state keys differ or loading fails.

  • ImportError – If torch/torchvision or winter_inference cannot be imported.

  • ValueError – If checkpoint input_size cannot be converted to int.

apple_predictor_predicted_compare.make_branch_prediction(rgb_path, depth_path, model_info, threshold: float)¶

Infer a square branch mask with training-compatible RGB-D scaling.

Reopens both images through winter.preprocess: centre crop, bilinear RGB, nearest-neighbour L depth, ImageNet RGB normalisation and depth/255. Uses inference_mode; the supplied model must already be in evaluation mode.

Parameters:

  • rgb_path – str or pathlib.Path to the RGB image.

  • depth_path – str or pathlib.Path to its registered depth image.

  • model_info – Six-element tuple returned by load_improved_model.

  • threshold – float in [0, 1]; inclusive sigmoid probability cutoff.

Returns:

uint8 [S, S] 0/255 prediction; S from model_info.

Return type:

numpy.ndarray

Raises:

  • OSError – If either image cannot be decoded.

  • RuntimeError – If inference or device transfer fails.

  • ValueError – If tuple unpacking or preprocessing dimensions fail.

apple_predictor_predicted_compare.read_predicted_mask(path: Path) → np.ndarray¶

Read a cached square grayscale mask and threshold intensities >127.

An all-zero mask is valid. A mask whose maximum is exactly 1 is rejected; other grayscale encodings are accepted and thresholded, not validated as strictly binary 0/255. Provenance and threshold compatibility are not checked.

Parameters:

path – pathlib.Path to an existing square PNG, normally encoded 0/255.

Returns:

uint8 [S, S] mask in {0, 255}.

Return type:

numpy.ndarray

Raises:

  • FileNotFoundError – If path is not a file.

  • ValueError – If dimensions are nonsquare or maximum intensity is 1.

  • OSError – If image decoding fails.

apple_predictor_predicted_compare.detect_and_export(frames, source, args, model_info=None)¶

Detect full-frame apple candidates using projected branch masks.

Uses detector.find_apple_candidates unchanged. Overwrites CSVs, metadata and matching annotation PNGs; old unmatched PNGs can remain. Custom paths can overwrite other experiments, so keep output directories distinct. branch_ms includes inference/read, mask save and alignment; detection_ms excludes branch prediction. total_ms excludes final CSV/metadata export and model loading, and is not winter’s model-only timing.

Parameters:

  • frames – Sequence of (RGB Path, parsed info dict, depth Path, GT Path).

  • source – str; predicted or gt. GT is thresholded >127 before projection.

  • args – argparse.Namespace from main; supplies output/mask paths, checkpoint, season, reuse_masks and probability threshold.

  • model_info – load_improved_model tuple; required for fresh predictions, unused for GT and cached-mask reuse.

Returns:

Number of processed frames. Writes counts/instances/timing CSVs, run_metadata.json and flat annotation PNGs; fresh predictions also write <RGB-stem>_branch.png square masks.

Return type:

int

Raises:

  • ValueError – If source or RGB/depth dimensions are invalid.

  • FileNotFoundError – If a required GT or cached mask is absent.

  • OSError – If image/CSV/metadata reading or writing fails.

  • RuntimeError – If branch inference fails.

Note

Reused masks are not fingerprinted. Metadata’s checkpoint and threshold describe the requested configuration, not verified cached-mask provenance.

apple_predictor_predicted_compare.run_comparison(traditional_dir: Path, output_dir: Path, args, source: str)¶

Run saved-CSV comparison and adapt its report prose for this workflow.

Matching and metric calculation belong to compare_apple_detectors.py. Report replacements depend on paragraph prefixes; they do not validate historical RF-DETR branch settings. Retain the reference run’s provenance.

Parameters:

  • traditional_dir – pathlib.Path containing counts and instances CSVs.

  • output_dir – pathlib.Path for comparison reports, CSVs, plots and examples.

  • args – argparse.Namespace with reference_dir, rgb_dir and max_distance.

  • source – str; predicted or gt, used for report interpretation.

Returns:

First summary_metrics.csv row; prints selected metrics.

Return type:

dict[str, str]

Raises:

  • subprocess.CalledProcessError – If the comparison subprocess fails.

  • OSError – If report or summary cannot be accessed.

  • StopIteration – If the summary has no data row.

apple_predictor_predicted_compare.build_frames(args)¶

Discover season-filtered RGB-D pairs, optionally requiring paired GT.

Searches lowercase PNG extensions nonrecursively, skips invalid names and missing depth with warnings. GT is required for gt source or also_gt_control, so enabling the control can reduce the predicted experiment’s frame set.

Parameters:

args – argparse.Namespace with rgb_dir, depth_dir, gt_dir, season, branch_source, also_gt_control and optional positive max_images.

Returns:

Sorted (RGB Path, parsed info dict, depth Path, GT Path), limited to the first max_images if supplied.

Return type:

list[tuple]

Raises:

RuntimeError – If no eligible complete pairs remain.

apple_predictor_predicted_compare.main(argv=None)¶

Parse options, produce predictions and optionally run comparisons.

Defaults to summer improved-U-Net branches and fixed existing RF-DETR CSVs. –branch-source gt uses gt_output_dir/gt_comparison_dir, not predicted paths. –reuse-masks skips model loading; –skip-comparison needs no reference CSVs. A requested GT control uses the same discovered frame set and apple filters.

Parameters:

argv – Sequence[str] or None; CLI arguments, or sys.argv[1:] when None.

Returns:

None. Writes experiment outputs and prints progress/summary metrics.

Raises:

  • SystemExit – For help, invalid threshold/image limit, redundant control, invalid CLI options or missing required reference CSVs.

  • RuntimeError – If no paired frames exist or model execution fails.

  • OSError – If required inputs/outputs cannot be accessed.

  • subprocess.CalledProcessError – If saved-CSV comparison fails.
