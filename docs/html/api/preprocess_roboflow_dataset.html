preprocess_roboflow_dataset¶

Source: src/preprocess_roboflow_dataset.py.

Statically extracted signatures and existing docstrings; no module execution.

Convert COCO apple-* categories into one apple class.

Maps data/apple tree.v1i.coco-segmentation/train and export to data/apple_tree_clean/train and valid. Retains all image records, including missing images whose copies are skipped. Annotation origin and independence from orchard evaluation require verification. Source path checks run on import.

raises FileNotFoundError:

If configured folders or annotation files are absent.

Example

python src/preprocess_roboflow_dataset.py

preprocess_roboflow_dataset.process_split(source_dir, annotation_file, output_dir)¶

Copy a COCO split and merge apple-* categories into class 1.

Keeps all images, including negative examples, and preserves segmentation geometry. Missing image records remain in COCO despite skipped copies; check output completeness separately. Reassigns annotation IDs sequentially.

Parameters:

  • source_dir – pathlib.Path containing images.

  • annotation_file – str or pathlib.Path; COCO JSON with images, annotations and categories.

  • output_dir – pathlib.Path; split destination created if needed.

Returns:

images, apple_instances, copied_images and missing_images.

Return type:

dict[str, int]

Raises:

  • RuntimeError – If no category starts with apple- (case-insensitive).

  • json.JSONDecodeError – If annotation JSON is invalid.

  • KeyError – If required category/image fields are absent.

  • OSError – If reading, copying or writing fails.

preprocess_roboflow_dataset.main()¶
