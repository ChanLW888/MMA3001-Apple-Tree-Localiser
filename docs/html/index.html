Apple Tree Localiser - MMA3001¶

Documentation for RGB-D branch segmentation and 2D apple localisation, including MLP/U-Net models, traditional detection, RF-DETR, comparison, optimisation and preprocessing. Detectors currently default to branch ground truth rather than an automatically connected branch-model pipeline.

The API reference uses existing docstrings and statically extracted signatures. Building this site does not import any project source module.
